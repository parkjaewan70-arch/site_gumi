# 구미 현장 GPS 관제 시스템

최대 80명 등록용 시험 운영 프로그램. 휴대폰의 동의 기반 GPS 전송을 서버가 받고 사무실 브라우저가 5초마다 조회합니다. 수동 지정과 가상 위치는 없습니다. 기존 ChatGPT 전용 사이트와 별개로 실행하는 독립 프로젝트입니다.

## 포함 기능
- 관리자 비밀번호 로그인(8시간 세션), 근로자 개인별 일회용 QR·초대 링크(24시간)
- 근로자 인증과 관리자 조회 권한 분리: 근로자는 타인 위치 조회 불가
- 휴대폰 GPS 최신 측정 전송(10초 타이머 및 GPS 갱신 이벤트), 서버 수신 확인
- 작업 시작 인원 / 최신 위치 수신 / 미확인 / 등록 인원을 구분
- 첨부 항공사진 위 이름 표시. 세 기준점의 실제 GPS를 입력하면 서버 공통 좌표 보정 적용
- 60초 초과 미수신은 주황색 마지막 위치 표시. 서버 조회 실패 시 오류 표시
- 작업 종료 성공 시 좌표 삭제, 위치 좌표는 24시간 후 주기적으로 삭제. SQLite 최신 위치만 저장하며 동선 이력 없음
- 카카오맵에서 마지막 좌표 열기. 카카오톡 위치 자동 수집은 구현하지 않음

## PC에서 빠른 확인
Node.js 24 이상 필요. `npm ci`, `.env.example`을 `.env`로 복사합니다.
로컬 확인용으로 PUBLIC_ORIGIN=http://localhost:3000, COOKIE_SECURE=false로 설정하고 ADMIN_PASSWORD를 16자 이상의 무작위 값으로 변경합니다.
`npm start` 후 PC에서 http://localhost:3000 접속. 이 주소는 다른 휴대폰에서 사용할 수 없습니다. 휴대폰 시험에는 아래 HTTPS 배포가 필요합니다.

## 실제 휴대폰 연결 (별도 서버 필요)
1. Docker 지원 서버, 도메인을 준비하고 도메인의 DNS를 해당 서버로 연결합니다. 포트 80/443을 개방합니다.
2. GitHub의 비공개 저장소에 이 폴더의 파일을 올립니다. `.env`, data, node_modules는 업로드하지 않습니다. 항공사진도 현장 정보이므로 공개 저장소에 올리지 마세요.
3. 서버에서 저장소를 clone하고 `.env`에 DOMAIN=실제도메인, PUBLIC_ORIGIN=https://실제도메인, 긴 ADMIN_PASSWORD를 설정합니다. 비용이 발생하는 서버 개설은 이 프로젝트가 수행하지 않습니다.
4. `docker compose up -d --build` 실행. Caddy가 인증서를 발급합니다. 도메인·인증서·방화벽 설정은 운영자가 확인해야 합니다.
5. 사무실 PC에서 https://실제도메인 접속 → 관리자 로그인 → 근로자 등록 → 개인 QR 발급.
6. 근로자 본인 휴대폰으로 QR 스캔. Chrome/Safari로 열기 → 동의 → 작업 시작 → 위치 권한 허용.
7. 사무실 PC의 관제 화면에서 자동 갱신 확인. 관리자 비밀번호는 근로자에게 공유하지 않습니다.
8. 항공사진의 지상 기준점 3곳과 그 위도·경도를 등록하세요. 직선상 지점은 사용할 수 없습니다. 보정 후 별도 알려진 지점에서 검증해야 합니다.

## GitHub
`.github/workflows/test.yml`은 push/PR에서 자동 검사합니다. GitHub Pages만으로 서버와 SQLite를 실행할 수는 없습니다. 이 패키지에 클라우드 자동 배포 자격증명은 포함하지 않았습니다.
업로드 예시: `git init`, `git add .`, `git commit -m "Add GPS control system"`, `git branch -M main`, `git remote add origin <본인 저장소 HTTPS 주소>`, `git push -u origin main`.
실제 GitHub 저장소 주소를 받아야 원격 반영 대상을 확정할 수 있습니다.

## 운영 한계와 인수 시험
브라우저 화면 잠금·절전·앱 전환에서 지속 실행을 보장하지 않습니다. 지속 백그라운드 관제는 별도의 서명된 Android/iOS 네이티브 앱이 필요합니다. 지하 통신 불능 시 실시간 전송 불가. GPS는 실내·층 식별을 보장하지 않습니다. 위치만으로 출역·체류·대피 완료를 확정할 수 없습니다. 사고 구조의 유일한 근거로 쓰지 마세요.
정확도 반경은 휴대폰 보고값이며 보정 후에도 오차가 남습니다. 비상 알림·SOS·집결 확인·출입 시스템 연계는 포함하지 않습니다.
실제 도입 전 5~10명으로 실내/옥외, 화면 잠금, 비행기모드, 복구, 종료·삭제, 관리자 접근 차단, 중복 이름, 80명 부하를 확인하세요. 자동 검사는 API·권한·좌표 변환이며 실기기·현장·80명 부하 시험을 대체하지 않습니다.
서버 원본 SQLite에는 최신 개인위치가 있으므로 백업·볼륨 접근 권한을 제한하세요. 사용자 단말 분실 시 관리자가 초대 재발급 또는 삭제로 인증을 폐기할 수 있습니다. 위치 수집 안내·동의 내용과 보관 정책은 실제 회사 운영에 맞게 확정해야 합니다.

## 개발 검사
`npm test` / `node --check server.mjs`. Node 내장 테스트와 임시 SQLite를 사용합니다.
